# okx_market_price_difference_tools
火币市场差价工具
### 使用手册
#### 安装插件
    1.打开浏览器 扩展程序管理页面
    2.扩展程序管理页面右上角开启开发者模式
    3.点击左上角加载已解压的扩展程序-选择解压后插件的文件夹
#### 使用插件
    1.进入火币官网现货交易市场
    2.收藏ETH\BTC\EOS\TRX
    3.切换到自选栏
    4.点击工具箱悬浮窗数据分析
#### 更新插件
    1.打开浏览器进入扩展程序管理页面找到对应插件点击刷新按钮
    2.进入火币官网现货交易市场页面刷新页面再使用工具
